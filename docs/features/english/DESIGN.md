이 문서는 현재 구현 동작을 설명한다. 승인한 학습 목표·섹션·난이도는 [장기 커리큘럼 로드맵](CURRICULUM_ROADMAP.md)을 따른다. 현재 통합 경로는 첫 주만 구현했으며, 2~24주는 준비 중이다.

## 오늘 학습: 첫 주 통합 경로

기본 진도는 `src/app/lib/english/learningPath.ts`의 `LEARNING_UNITS`다. `EnglishJourney`는 `buildLearningPath`가 생성한 레슨을 공통 화면으로 제공한다. 단어와 문장을 오늘의 목표 안에서 연결하며, 기존 문장·단어 목록은 접힌 보조 학습 영역에 남긴다.

| 회차 | 목표 | 채점 문항 수 |
| --- | --- | --- |
| 1 | Hello, I, I am + 이름 | 17 |
| 2 | happy/tired와 I am | 17 |
| 3 | you, You are와 배운 상태 | 14 |
| 4 | okay/ready와 I am / You are | 23 |
| 5 | 새 내용 없는 누적 복습 | 20 |
| 6 | 힌트 없는 확인과 배운 요소의 작은 재조합 | 10 |

총 101문항은 같은 단어·문장을 여러 형태로 반복한 횟수다. 첫 주에는 `Are you` 질문을 요구하지 않는다. 새 학습은 단어 뜻 선택→영단어 선택→단어 입력, 문장 선택→조립→듣기→문장 입력으로 진행한다. 지난 표현 회상이 새 내용보다 먼저 나온다. 6회차 확인은 모범 문장·힌트를 숨기며, 오답 재연습에서는 해당 표현의 선택·조립부터 다시 지원한다.

기본 버튼은 첫 미완료 회차를 안내한다. 오늘 이미 통합 회차를 완료했다면 복습을 기본으로 제안하고 다음 회차는 별도 버튼으로 선택한다. 복습만 한 날은 새 학습 완료로 취급하지 않는다. 회차 완료는 풀이 완료이며 숙련 인증이 아니다.

15분은 목표 시간이다. 중간에 ‘여기까지 저장하고 나가기’로 채점한 접두 구간의 문항 수·정답 수·오답 ID만 저장하고 다음 접속에서 다음 문항부터 이어간다. 입력 원문은 저장하지 않는다. 중간 저장은 0 XP이며 최종 완료 때 전체 정답 XP를 별도 세션 ID로 저장한다. 저장 실패 시 풀이를 유지하고 재시도한다. 기존 XP·기록은 보존하고 통합 진도와 보조 진도는 별도로 판정한다.

### 원본 데이터로 확장하기

1. `vocabulary.ts`에 필요한 단어의 `word`, `meaning`, `example`, `exampleMeaning`을 추가한다.
2. `LEARNING_UNITS`에 안정적인 단원 ID·주차·목표와 문장 원본(`id`, `text`, `meaning`, `requires`, 선택적인 `acceptableAnswers`)을 추가한다.
3. 회차에 목표·설명, 모드(`learn` / `review` / `check`), 도입 개념(`introduces`), 선수 개념(`requires`), 단어·문장 참조를 지정한다.
4. `reviewWords`, `reviewSentences`로 이미 배운 내용을 연결한다. 다른 단원의 문장은 `단원ID:문장ID`로 참조한다. `transferSentences`는 확인 회차에서만 배운 요소의 새 조합을 지정한다.

문항·안내 카드·듣기·말해 보기·오답 재연습·진도 카드는 같은 생성기와 UI를 재사용한다. 새로운 문제 유형 자체를 도입하는 경우에는 로직 수정이 필요하다. `LEARNING_SETTINGS`에서 목표 시간, 듣기·말하기 수, 음성 속도를 관리한다. 단원별 화면 분기는 추가하지 않는다.

생성기는 중복 ID, 없는 단어·문장 참조, 충족되지 않은 선수 개념, 미학습 내용의 복습 참조를 거부한다. 이 검증은 어휘·문법의 교육적 타당성을 자동 증명하지 않으므로 저자가 선수 지식 태그와 문장을 함께 검수해야 한다. 기존 문항의 순서·ID를 바꾸면 저장한 이어하기 위치에 영향을 줄 수 있어, 진행 중 데이터는 안정적으로 유지한다.

### 듣기와 말해 보기

브라우저의 영어 음성으로 작성된 문장을 재생한다. 듣기 문항은 재생 종료 또는 사용자의 명시적인 글 대체 선택 이후 답할 수 있다. 영어 음성이 없거나 재생에 실패하면 글로 연습할 수 있다. 결과의 듣기·글 대체·힌트 사용 수는 이번 접속에서 관찰한 수이며 장기 성취 기록이 아니다.

마지막에는 배운 문장을 소리 내어 말해 보는 자기 확인을 제공한다. 녹음·발음 자동 채점·말하기 능력 판정은 없다. 사용자는 글 연습만 마치는 선택도 할 수 있다. 기기의 음성 설치·브라우저 지원에 따라 실제 음성이 달라진다.

## 보조 문장 커리큘럼

보조 문장 문제의 원본은 `src/app/lib/english/curriculum.ts`다. 24개 레슨마다 표현 6개를 선택 6문항, 조립 6문항, 입력 6문항으로 반복한다. 총 432문항은 세 유형을 포함한 수이며, 모두 서로 다른 문장이라는 뜻은 아니다.

| 챕터 | 레슨 수 | 학습 내용 |
| --- | --- | --- |
| 1 | 7 | I am, You are, He/She is, It is, We are, They are, 혼합 복습 |
| 2 | 7 | be동사 부정문 3개 레슨, 주어별 be동사 의문문 4개 레슨 |
| 3 | 8 | a/an, have, want, like, 일상 동작, do not, Do 의문문 |
| 4 | 2 | 앞에서 배운 어휘와 문법으로 구성한 누적 독해 |

보조 문장 목록에는 현재형 일반 동사의 he/she/it 변화, 과거형, 듣기와 발음 평가를 포함하지 않는다.

## 단어 원본과 문제 생성

`src/app/lib/english/vocabulary.ts`의 `VOCABULARY_UNITS`가 단어 학습의 원본이다. 묶음에는 안정적인 `id`, 제목, 품사를 두고, 각 단어에는 `word`, `meaning`, `example`, `exampleMeaning`을 저장한다. 현재 인사, 대명사, 기분과 상태, 크기와 온도, 사람과 학교, 주변 사물·동물, 음식, 기본 동사, 색깔, 숫자, 일상 동작 11묶음에 고유 단어 64개가 있다.

`createVocabularyLesson`이 원본에서 다음 문제를 자동 생성한다. 192문항은 단어 64개를 세 유형으로 반복한 수다.

1. 영어를 보고 한국어 뜻 고르기 (`choice`).
2. 같은 뜻을 보고 영단어 고르기 (`word-choice`).
3. 두 선택형에서 만난 영단어 직접 입력 (`write`).

뜻과 품사, 예문은 학습 시작 전에 카드로 확인할 수 있다. 예문은 쓰임을 보여 주는 참고이며 예문의 문법이나 문장 전체를 입력 문제로 요구하지 않는다. 새 묶음은 원본만 추가하면 목록·안내 카드·문제·오답 재연습·복습에 반영된다. 묶음에는 선택지를 만들 수 있도록 단어와 뜻이 서로 다른 단어가 최소 3개 있어야 한다. 현재 원본의 뜻은 학습하는 대표 의미이며 모든 품사·사전적 의미를 포괄하지 않는다.

보조 단어 묶음은 문장 진도와 별개로 선택할 수 있다. 오늘 학습에서는 같은 단어 원본을 회차 목표에 맞게 재사용한다. 단어 복습은 완료한 단어 묶음에서만 4개 단어를 골라 세 유형 12문항으로 연습한다. 문장 복습에 미학습 단어 문제가 섞이지 않으며 단어 완료가 문장 레슨을 해금하지 않는다.

## 보조 문장 학습 흐름

1. 시작 화면에서 문법과 여섯 표현의 영어·한국어 뜻을 먼저 확인한다.
2. 모든 표현을 선택형으로 연습한 뒤 조립으로 다시 연습한다.
3. 이미 선택·조립으로 만난 표현만 직접 입력한다. 필요하면 학습 카드를 다시 펼친다.
4. 각 문항은 정답과 해설을 제공한다. 선택지와 단어 타일은 학습 시작마다 섞는다.
5. 결과에서 틀린 표현을 다시 연습할 수 있다. 실패한 입력 문항 하나만 반복하지 않고 해당 표현의 선택·조립·입력을 모두 다시 푼다.

be동사 의문문은 대응하는 평서문 연습 뒤에 나온다. 예를 들어 `You are okay.`는 2번째 레슨, `Are you okay?`는 11번째 레슨에서 배운다. 의문문 레슨 안내에는 be동사를 주어 앞으로 옮기는 규칙을 설명한다. 독해에는 선수 레슨에서 도입한 어휘만 쓰며, 선택형에서는 뜻을 확인하고 조립·입력에서는 문장을 만든다.

## 보조 학습 복습과 기록

- 배운 레슨에서 표현 4개를 골라 선택·조립·입력 12문항으로 복습한다. 레슨별 가장 최근 학습 기록의 오답 표현을 우선한다.
- 오답 재연습도 `review` 활동으로 기록한다. 정답마다 10 XP를 얻는다.
- 다음 레슨은 앞선 레슨의 확장 분량을 모두 완료한 뒤 열린다. 완료는 풀이를 끝냈다는 뜻이며 정답률로 측정한 숙련 인증은 아니다.
- 기존 레슨 ID `hello`, `people`, `things`, `cafe`, `reading`은 유지한다. 기존 3문항 학습 기록과 XP는 삭제하지 않는다.
- 완료 판정은 해당 레슨의 현재 문항 수 이상을 푼 `lesson` 기록을 기준으로 한다. 이전 3문항 완료자는 확장된 18문항을 다시 완료해야 하며 화면에 이를 안내한다.
- DB 스키마 변경은 없다. 저장 필드는 [DATABASE.md](DATABASE.md)를 따른다.
- 단어 학습도 `lesson` 활동을 사용하며 `lesson_id`는 `vocabulary-{묶음 id}`다. 단어 복습·오답 재연습은 `review`, `lesson_id: vocabulary-review`로 저장해 최근 기록에서 문장 복습과 구분한다. XP와 학습일은 함께 집계하고 완료 지도는 별도로 집계한다.

## 검증

`tests/english-curriculum.test.mjs`는 문항 수·ID 중복, 선택→조립→입력 순서, be동사 질문의 선행 평서문, 유일한 정답, 타일 구성, 축약형, 독해 선행 어휘, 복습과 오답 재연습, 기존 기록 완료 판정을 검사한다.

Node.js 22.18 이상에서 `node --test tests/english-curriculum.test.mjs`로 실행한다. 앱 런타임 요구사항을 바꾸지는 않는다.

단어 생성·선택형 선행·유일한 정답·새 원본 묶음 재사용·오답 복습·문장 진도 분리·혼합 문제 순서·잘못된 원본 거부는 `node --test tests/english-vocabulary.test.mjs`로 검사한다.

`tests/english-learning-path.test.mjs`는 첫 주 순서·선행 노출·문항 구성, 두 번째 단원을 데이터만으로 추가하는 확장과 단원 간 복습, 잘못된 참조 거부, 확인 오답 지원, 복습 중복 제거, 기존·중간 기록의 완료 분리를 검사한다. 세 파일 합계 23개 테스트다.

가상 계정 브라우저 검증은 첫 주 6회차 전체 101문항, 중간 저장·재접속·XP 보존, 모바일 배치, 같은 날 복습, 저장 실패 재시도와 음성 실패·미지원의 글 대체를 확인했다. DB 응답과 음성 재생 이벤트는 모의 처리했으며, 실제 계정 쓰기·기기 음질·실사용 15분 적합성은 확인하지 않았다.
