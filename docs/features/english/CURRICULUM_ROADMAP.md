# 영어 학습 로드맵

## 변경 기록

- 2026-10-16: 사용자 승인에 따라 첫 주 통합 경로를 구현함. 데이터 확장 방식·중간 저장·기기 음성·말하기 자기 확인의 현재 범위와 후속 계획을 구분함.

- 2026-10-16: Duolingo 공식 설계 자료와 CEFR을 확인하고, 하루 15분의 일상·여행 기초에서 업무 영어로 확장하는 학습 경로 초안을 작성함. 초기 문법 부하와 음성 기능 부재에 대한 독립 검토를 반영함.

## 상태와 확정 조건

사용자가 정한 목표는 일상·여행 영어를 먼저 익히고 그 기반을 업무 영어로 확장하는 것이다. 하루 학습 시간은 15분이다. 한국어를 사용하는 성인 초보를 대상으로 가정한다. 알파벳을 읽고 입력하는 능력은 아직 진단하지 않는다. 첫 회차에 선택적인 따라 입력 준비를 제공하며, 정식 시작 진단은 후속 범위다.

사용자는 일상·여행에서 업무로 이어지는 방향과 하루 15분 계획을 승인했다. 첫 주 6회차·101문항의 통합 경로를 구현했으며, 2~24주는 앱에서 준비 중으로 표시한다. 월별 기간·학습량·숙련 기준은 실사용에 따라 조정할 설계값이다. 현재 구현 동작은 [DESIGN.md](DESIGN.md)에 기록한다.

## 공식 자료에서 확인한 설계 원칙

Duolingo는 먼저 수준별 의사소통 목표와 그 목표에 필요한 어휘·표현·문법을 정리한 다음 단원을 구성한다고 설명한다. 어휘와 문법은 상황 안에서 함께 다루고, 새로운 내용은 이미 배운 요소로 만든 문장에 조금씩 도입한다. 이는 현재 앱의 문법 목록과 독립 단어 목록만으로 전체 학습 경로를 결정하기 어렵다는 판단의 근거다. [공식 과정 설계 설명](https://blog.duolingo.com/the-nuts-and-bolts-of-course-creation-at-duolingo/)

Duolingo의 교수법 설명은 쉬운 과제로 패턴을 알아차리게 한 뒤 새 맥락에 적용하도록 난도를 높이고, 힌트와 짧은 설명을 제공한다고 밝힌다. 우리도 선택형 정답을 외운 결과와 도움 없이 표현을 떠올리는 능력을 구분한다. [공식 교수법](https://blog.duolingo.com/duolingo-teaching-method/)

학습 경로 설계 설명에는 새로운 내용, 지난 내용의 복습, 수준에 맞는 이야기를 기본 경로에 함께 배치하는 원칙이 나온다. 복습 설명에는 경과 시간과 정확도를 함께 고려하고 어려운 내용을 더 일찍 다시 다루는 원칙이 나온다. [학습 경로 설계](https://blog.duolingo.com/new-duolingo-home-screen-design/), [간격 반복 설명](https://blog.duolingo.com/spaced-repetition-for-learning/)

CEFR은 기간이나 문제 수보다 언어로 할 수 있는 일을 기술한다. A1은 익숙한 기본 표현, 자기소개, 개인 정보에 관한 간단한 질문과 답변, 상대의 도움을 전제로 한 상호작용을 포함한다. 이 초안은 해당 기초 능력 중 일부를 학습 목표로 삼는다. [유럽평의회 공식 수준 설명](https://www.coe.int/en/web/common-european-framework-reference-languages/table-1-cefr-3.3-common-reference-levels-global-scale)

위 자료에서 확인한 것은 설계 원칙이다. 예전 공식 글에 나온 화면, 코스 길이, 문항 수를 현재 한국어 사용자를 위한 영어 코스의 정확한 구성으로 단정하지 않는다. 아래 월별 주제·시간 배분·복습 간격·통과 기준은 우리 서비스의 제안이며 Duolingo의 실제 수치가 아니다.

## 목표 기간과 난이도 해석

- 한 계획 월은 4주다. 첫 6개 구간은 24주이며 달력상 정확히 6개월과 같지는 않다.
- 주 6일을 기준으로 하루 15분이면 24주 동안 36시간이다. 주 7일 학습은 선택사항이며 필수 진도를 추가하지 않는다.
- 기간은 예상 경로다. 장기적으로 시작 진단과 수행 결과에 따라 아는 부분을 건너뛰고 어려운 부분을 더 연습한다. 현재는 회차 순서와 오답 재연습을 제공한다.
- 난이도는 문장 길이만으로 판단하지 않는다. 새 어휘, 새 문법, 힌트 양, 듣기 조건, 스스로 만들어야 하는 분량을 따로 관리한다.
- 첫 과정은 초보의 실용 표현 토대를 목표로 한다. 36시간을 A1·A2·B1 자격이나 자유로운 회화 능력으로 환산하지 않는다.

## 첫 6개 계획 월

아래 성과는 학습한 어휘와 상황에 한정한다. 읽기·작성은 앱 과제로 확인할 수 있으며 듣기·말하기 성과는 음성 콘텐츠와 별도 수행 확인이 필요하다.

| 구간 | 섹션 주제 | 새로 도입하는 핵심 | 구간 끝에서 확인할 행동 |
| --- | --- | --- | --- |
| 1개월 · 1~4주 | 인사, 나와 다른 사람, 기분·상태 | 주어별 be동사 평서문, 부정문, 기본 질문을 순서대로 | 자신과 다른 사람을 짧게 소개하고 준비·기분을 묻고 답한다 |
| 2개월 · 5~8주 | 가진 것, 취향, 원하는 것, 하루의 행동 | a/an·소유 표현, have/like/want, I/you 일반 현재, do not/Do | 가진 것·좋아하는 것·일상을 3~5개의 짧은 문장으로 표현한다 |
| 3개월 · 9~12주 | 카페, 가격·수량, 가게, 식당 | 공손한 주문 표현, 기초 숫자·복수, 가격 질문, this/that | 간단한 메뉴·가격을 읽고 원하는 품목과 수량을 주문한다 |
| 4개월 · 13~16주 | 장소, 주변 위치, 이동, 숙소 | Where, 기초 위치 표현, there is/are, 시각·예약 표현 | 익숙한 장소를 찾고 짧은 방향 안내·시간표·예약 확인을 이해한다 |
| 5개월 · 17~20주 | 다른 사람의 일상, 지금 하는 일 | he/she 일반 현재와 does를 나눠 도입한 뒤 현재진행형 | 평소 행동과 지금 하는 행동을 구분하고 짧게 묻고 답한다 |
| 6개월 · 21~24주 | 가까운 계획, 도움 요청, 생활 메시지, 여행 종합 | going to, 기본 can 요청·응답, 앞선 내용 재사용 | 가까운 계획과 필요한 도움을 표현하고 학습한 여행 상황을 연결한다 |

## 주별 단원과 선수 지식

한 주는 기능 목표 하나를 가진 단원이다. 새 학습 4일, 누적 복습 1일, 짧은 수행 확인 1일로 구성한다. 각 날의 레슨은 단원 안에서 더 작게 나눈다.

| 주 | 단원 목표 | 도입과 복습 순서 |
| --- | --- | --- |
| 1 | 인사하고 나와 상대의 상태 말하기 | 인사 고정 표현, I am, You are. 같은 상태 어휘로 주어만 바꿔 연습한다 |
| 2 | 다른 사람과 물건 하나 말하기 | he/she/it와 is. a student 같은 필수 명사구는 뜻과 함께 먼저 노출한다 |
| 3 | 우리·그들의 상태와 부정 말하기 | we/they와 are를 익힌 뒤 이미 아는 평서문에 not을 붙인다 |
| 4 | 안부·준비 상태 묻고 답하기 | 앞서 연습한 be동사 평서문을 질문으로 바꾸고 짧은 긍정·부정 답을 익힌다. 첫 누적 평가 |
| 5 | 가진 물건 말하기 | 물건 명사, a/an, my/your를 작은 레슨으로 나눠 다룬 뒤 I/you have와 결합한다 |
| 6 | 좋아하는 것과 원하는 것 말하기 | 이미 아는 음식·물건으로 like와 want를 서로 다른 레슨에서 도입한다 |
| 7 | 하루에 하는 행동 말하기 | I/you + read/eat/drink 등의 일반 현재. be동사와 일반 동사를 비교한다 |
| 8 | 행동을 부정하거나 물어보기 | 배운 일반 현재에서 do not을 먼저 연습한 뒤 Do you 질문을 익힌다 |
| 9 | 카페에서 주문하기 | 배운 음식·음료와 please를 활용한다. I’d like는 고정 주문 표현으로 먼저 익히며 would 문법은 요구하지 않는다 |
| 10 | 가격과 수량 표현하기 | 필요한 숫자·가격 읽기, 명사 복수의 기본형, 수량 표현, How much 고정 질문을 작은 레슨으로 나눈다 |
| 11 | 가게에서 물건 고르기 | this/that와 배운 색깔·물건으로 선택을 표현한다. these/those의 체계적 확장은 뒤로 미룬다 |
| 12 | 식당에서 짧게 주문하기 | 메뉴 읽기, 음식·음료·수량·공손한 표현의 재조합. 새 문법보다 누적 적용에 집중한다 |
| 13 | 장소가 어디인지 묻기 | 기존 be 질문에 Where를 도입하고 in/on/near 등의 위치 표현을 차례로 익힌다 |
| 14 | 주변 장소와 간단한 안내 이해하기 | 알려진 단수·복수 명사에 there is/are를 도입한다. left/right/straight 안내는 짧은 표현으로 학습한다 |
| 15 | 이동 시간과 목적지 확인하기 | 앞서 배운 숫자, 시각의 기본형, at + 시각, 교통 어휘. 복잡한 경로 설명은 요구하지 않는다 |
| 16 | 숙소에서 예약 확인하기 | I have a reservation 같은 배운 문법의 새 상황 적용. 이름·방 번호·기초 안내 읽기 |
| 17 | 다른 사람의 평소 행동 설명하기 | I/you의 일반 현재를 복습하고 he/she + 동사 변화의 평서문만 먼저 익힌다 |
| 18 | 다른 사람의 행동을 묻고 부정하기 | does/does not 뒤의 동사원형을 분리해 연습한다. 17주의 긍정문과 비교한다 |
| 19 | 지금 하는 행동 말하기 | be동사를 먼저 복습하고 read/eat/drink 같은 알려진 동사의 -ing형을 노출한 뒤 현재진행형 평서문을 익힌다 |
| 20 | 지금 하는 행동 묻고 답하기 | 19주 평서문과 기존 be 질문·부정을 결합한다. 평소 행동과 지금 행동을 같은 어휘로 비교한다 |
| 21 | 가까운 계획 말하기 | be동사·동사원형을 복습한 뒤 am/is/are going to + 동사의 기본 예문을 익힌다. 모든 시제 비교를 한꺼번에 요구하지 않는다 |
| 22 | 도움을 요청하고 가능한 일 말하기 | 알려진 행동 어휘에 can을 도입한다. I need help 등 필요한 도움 표현을 작은 묶음으로 익힌다 |
| 23 | 생활 메시지 주고받기 | 상태·일정·계획·요청을 2~3개의 짧은 문장으로 연결한다. 본격적인 업무 이메일은 아직 요구하지 않는다 |
| 24 | 익숙한 여행 상황 연결하기 | 카페·식당·길·숙소를 연결한 누적 과제. 새 문법을 추가하지 않고 약한 목표를 재연습한다 |

소유 표현, 관사, 부정, 질문을 첫 레슨에 한꺼번에 넣지 않는다. 1개월에는 필요한 표현을 이해하는 수준으로 시작하고 체계적인 확장은 해당 단원에서 한다. 과거형·관계절·현재완료는 첫 24주 필수 범위에서 제외한다.

## 하루 15분의 기본 경로

기본 버튼은 사용자가 오늘 풀 문제 종류를 고르게 하기보다, 현재 목표와 필요한 복습을 안내한다. 단어와 문장을 무작위로 섞는 방식도 사용하지 않는다.

| 시간 | 활동 | 설계 기준 |
| --- | --- | --- |
| 3분 | 지난 내용 회상 | 지난 단어·표현·오답을 경과 시간과 어려움에 따라 다시 꺼낸다 |
| 8분 | 오늘 상황의 짧은 레슨 | 같은 의사소통 목표 안에서 어휘, 문장 구조, 읽기와 듣기를 연결한다 |
| 3분 | 작은 사용 과제 | 힌트를 줄인 문장 작성 또는 짧은 응답·따라 말하기를 한다 |
| 1분 | 정리 | 오늘 다룬 목표, 도움이 필요했던 내용, 다음 복습을 보여 준다 |

시간은 초안이며 실제 풀이 속도로 조정한다. 15분을 넘겨 정해진 문항 수를 억지로 채우게 하지 않는다. 단어장과 별도 복습은 선택형 보조 경로로 남긴다.

첫 주에는 읽기·선택·조립·입력, 기기의 영어 음성으로 듣기, 소리 내어 말해 보기 자기 확인을 제공한다. 음성을 지원하지 않으면 명시적으로 글 연습으로 대체한다. 텍스트 정답률을 듣기·말하기 성과로 표시하지 않으며 발음 자동 평가는 없다. 첫 주 복습은 데이터에 지정한 누적 복습과 오답 우선 복습이고, 경과 시간에 따른 개인화 간격 반복은 후속 구현이다.

## 첫 주 상세 예시

| 학습일 | 새로 다룰 핵심 | 이미 배운 내용의 재사용 |
| --- | --- | --- |
| 1일 | Hello, I, I am + 이름 | 인사와 이름의 뜻·소리·입력 방법부터 연결한다 |
| 2일 | happy/tired와 I am | 이름 소개를 회상하고 같은 I am 구조에서 상태를 말한다 |
| 3일 | you, You are | 전날 상태 어휘를 그대로 쓰며 I am과 You are를 비교한다 |
| 4일 | okay/ready와 두 주어 | 알려진 문법에 새 상태만 더한다. 아직 Are you 질문을 입력시키지 않는다 |
| 5일 | 새 핵심 없음 | 앞선 표현을 다른 순서와 맥락에서 골라 보고 만들고 써 본다 |
| 6일 | 새 핵심 없음 | 이름·상태의 작은 수행 과제로 힌트 없이 가능한 것과 복습할 것을 확인한다 |

Are you okay?는 You are okay.의 뜻·형태를 익히고 be 질문을 도입한 다음에 나온다. 인사에서 유용한 고정 질문을 더 일찍 넣는다면, 그 질문 자체를 별도 목표 표현으로 먼저 가르쳐야 하며 처음 보는 문장 전체를 입력 정답으로 요구하지 않는다.

## 반복량과 숙련 확인

문항의 단순 총합으로 커리큘럼 볼륨을 평가하지 않는다. 다음 수치를 구분한다.

- 서로 다른 핵심 단어·의미·표현의 수.
- 같은 목표를 다른 상황에서 연습하는 예문의 수.
- 선택·조립·입력·듣기·응답 등의 연습 횟수.
- 며칠 뒤 다시 꺼내 보았을 때 유지되는 정도.

저작 예산의 시작 범위는 새 학습일에 새로운 의미·표현 2~3개, 주 8~12개다. 첫 24주에서 약 180~300개의 핵심 의미·표현을 다루는 범위를 검토하되, 이를 모두 외웠다는 성과로 계산하지 않는다. 기존 단어를 새 문장에 적용하는 연습을 충분히 넣으며 고정 총량을 맞추려고 새 단어를 추가하지 않는다.

처음에는 같은 목표의 선택·조립 뒤에 입력을 배치한다. 이후 누적 평가에서는 학습한 단어와 문법의 새로운 조합도 확인한다. 같은 문장을 세 번 맞혔다는 사실만으로 응용 능력을 판정하지 않는다. 틀리면 더 쉬운 지원으로 돌아간 뒤 시간 간격을 두고 다시 확인한다.

복습 일정의 실험 시작값으로 다음 날, 3일 뒤, 7일 뒤, 14일 뒤를 고려한다. 이 수치는 확정 알고리즘이나 Duolingo의 내부 간격이 아니다. 어려운 목표는 더 일찍, 유지되는 목표는 간격을 늘려 배치한다. 휴식일·결석이 있어도 과도한 복습 적체로 새 학습을 막지 않도록 학습 시간 안에서 조절한다.

레슨 완료와 목표 숙련은 별도로 관리한다. 첫 평가 제안은 다음과 같다.

1. 힌트 없이 학습한 문장·짧은 상황을 이해한다.
2. 선택 없이 핵심 표현 몇 개를 떠올려 쓸 수 있다.
3. 적어도 다음 학습일에 일부 목표를 다시 확인한다.
4. 듣기·말하기는 해당 활동을 실제로 수행했을 때만 별도로 기록한다.

8~12개의 누적 과제에서 약 80% 이해와 2~3개의 독립 작성 성공을 재연습 필요 여부의 초기 신호로 검토한다. 표본이 작으므로 이를 단독 잠금 조건이나 공인 수준 판정으로 쓰지 않는다. 오타·다른 자연스러운 정답과 목표 문법 오류도 구분해야 한다. 기준이 어려우면 다음 목표와 병행해 약점을 복습하며 같은 레슨을 무한 반복시키지 않는다.

## 6개월 뒤: 일상·여행에서 업무로

일상·여행·업무는 서로 배타적인 코스가 아니다. 사람과 상태, 소유, 행동, 시간, 계획, 요청이라는 공통 토대를 다른 상황에서 사용한다. 전문적인 문서·회의의 복잡성은 별도 확장이 필요하다.

| 후속 구간 | 방향 | 할 수 있는 일의 예 |
| --- | --- | --- |
| 7~9개월 | 기초 보강, 기본 과거, 일상 확장, 업무 입문 | 어제 한 일·현재 상태·다음 계획을 짧게 표현하고 템플릿을 이용해 일정이나 도움 메시지를 작성한다 |
| 10~12개월 | 짧은 업무 메시지·메일·공지 | 일정 확인, 간단한 요청·사과·진행 공유를 여러 개의 짧은 문장으로 표현하고 익숙한 짧은 공지를 이해한다 |
| 이후 | 직무와 실제 자료에 따른 확장 | 개발 문서, 이슈·PR 설명, 회의, 고객 응대 등 필요한 분야를 선택해 어휘·읽기·상호작용을 확장한다 |

이 역시 기간 보장보다 선수 능력으로 연결한다. 본격적인 회의나 전문 문서 독해를 짧은 생활 메시지와 같은 난도로 표시하지 않는다. 복잡한 업무 수행을 목표로 한다면 하루 15분 외의 실제 읽기·듣기·사용 경험도 학습 계획에 포함할 필요가 있다.

## 현재 콘텐츠를 다루는 방법

현재의 보조 문장 432문항과 단어 192문항은 재사용할 수 있는 초기 재료다. 세 유형으로 바꾼 횟수를 모두 서로 다른 예문으로 세지 않는다. 이 분량이 곧 6개월 커리큘럼을 완성했다는 의미도 아니다.

1. 기존 단어와 문장을 새 단원 목표에 배정한다. 해당 단원의 선수 지식이 부족한 문항은 먼저 도입하거나 뒤로 옮긴다.
2. 모든 단어·문법·목표 표현에 도입 위치를 정한다. 문항은 학습 목표와 선수 지식을 참조해야 한다.
3. 단어는 오늘의 상황 안에서 먼저 만나고 문장·이해·작성 과제로 이어진다. 별도 단어 목록은 보조 학습에 재사용한다.
4. 누적 복습과 수행 확인에 필요한 변형 예문을 채운다. 사용자가 느낀 Are you okay?의 도약을 검수 사례로 삼는다.
5. 기존 XP·학습 기록을 보존한다. 새 통합 진도는 기존 보조 진도와 구분하며 기존 완료가 통합 단원을 건너뛰게 하지는 않는다.

## 구현 현황과 다음 확장

첫 단원의 통합 학습 로직을 완성했다. 단어 원본과 단원의 목표·선수 개념·문장·회차별 도입/복습/확인 참조를 추가하면 공통 생성기와 화면이 재사용된다. 두 번째 단원을 데이터만 추가하는 테스트로 문제 생성·단원 간 복습·다음 회차 이동을 확인했다.

다음은 2~4주 데이터를 이 순서와 기준에 맞게 저작·검수하는 일이다. 5~24주 전체 콘텐츠, 정식 시작 진단, 개인화 간격 반복, 발음 평가와 업무 과정은 아직 제공하지 않는다. 실제 15분 풀이와 기기 음성을 확인한 뒤 회차 분량을 조정한다.
