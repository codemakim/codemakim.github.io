# 프로젝트 작업 기록

완료하고 확인한 주요 변경을 날짜별로 요약한다. 상세 구현은 Git 기록과 관련 설계 문서, 게시글의 업데이트 기록을 본다. 이 기록은 2026-10-15부터 시작하며 과거 내역을 모두 소급 작성하지 않는다.

## 기록 규칙

- 날짜는 한국 시간(Asia/Seoul) 기준으로 쓴다.
- 기능, 개선, 배포, 게시글 등록·실질 수정, 운영 변경을 한 줄로 요약하고 관련 문서나 커밋을 연결한다.
- 완료·확인된 내용만 기록한다. 미완료 계획, 실패한 시도, 맞춤법·서식만 바꾼 작업은 기록하지 않는다.
- 최신 날짜를 위에 추가한다. 같은 날 항목은 유형별로 나눈다.
